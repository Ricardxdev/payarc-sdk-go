# Delete a Coupon

This API deletes a coupon.

### Deleting Coupons

Coupons can be deleted via the coupon management page of the PAYARC dashboard. However, deleting a coupon does not affect any customers who have already applied the coupon; it only means that new customers can’t redeem the coupon.

Coupons can also be deleted via the API.
